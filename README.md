# Тестовое задание: Просмотр установленных приложений Android

## 📱 Описание

Необходимо разработать Android-приложение, отображающее информацию об установленных на устройстве приложениях.

Приложение должно работать на устройствах с **Android 7.0 (API 24) и выше**.  
Ограничений по используемому стеку технологий **нет**.

---

## 🧩 Функциональные требования

### 1. Экран со списком приложений
- Отображает список всех установленных на устройстве приложений

### 2. Экран с подробной информацией
При нажатии на элемент списка должен открываться экран с подробной информацией о выбранном приложении.

Экран должен содержать:
- **Название приложения**
- **Версию приложения**
- **Имя пакета**
- **Контрольную сумму APK-файла**

### 3. Контрольная сумма
- Алгоритм контрольной суммы можно выбрать самостоятельно  
  (например: `SHA-1`, `MD5`, `CRC32` или любой другой)

### 4. Запуск приложения
- На экране с информацией о приложении должна быть кнопка, позволяющая **запустить выбранное приложение**
